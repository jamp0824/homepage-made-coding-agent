# Frontend

Next.js preview and test-reference screens live here.

This folder is intentionally separate from the core automation harness:

- Core generation scripts stay in `../scripts`.
- Validation rules stay in `../harness`.
- Request schemas stay in `../schemas`.
- Generated output stays in `../generated-sites`.
- Job queues stay in `../jobs`.

Run from the repository root:

```bash
npm run dev
npm run build
```
