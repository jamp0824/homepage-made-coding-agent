# Project Intent

## Correct Understanding

고객이 홈페이지 만들기 STEP을 완료하면 기존에는 회사 내부 사람이 그 입력 정보를 보고 홈페이지를 수동 제작했다.

이번 프로젝트의 목표는 그 수동 제작 작업을 Goose 기반 무료/오픈소스 Coding Agent로 자동화하는 것이다.

## Not This

- 고객에게 AI 챗봇을 제공하는 프로젝트가 아니다.
- 고객 입력 문구만 예쁘게 다듬는 기능이 아니다.
- 고객이 직접 Goose를 쓰는 기능이 아니다.
- 담당자가 결과를 승인하는 내부 검수 화면이 아니다.
- 외부 서비스 템플릿을 복제하는 프로젝트가 아니다.

## This

- 고객 신청 데이터를 기반으로 홈페이지를 자동 제작하는 시스템이다.
- Goose가 홈페이지 파일을 생성한다.
- ChatGPT/Claude/Gemini API 또는 구독 연동을 모델로 사용한다.
- Harness가 자동 검증자 역할을 한다.
- 검증 통과 시 홈페이지 생성 완료 상태로 전환한다.
- 자동화 실패 건만 manual_required로 보낸다.
