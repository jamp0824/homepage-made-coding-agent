** 비고(정책/확장 고려)
상품중심형 vs 회사소개중심형 차이
상품중심형: 상품 갤러리/견적·구매 CTA 중심 섹션이 기본 포함 (상품 존재 시 강화)
회사소개중심형: 회사 스토리/포트폴리오/연혁 섹션 확장
기존 기업카드 보유 회원 자동 생성 정책
정/준회원 중 기업 카드 생성된 회원은 보유 정보 수준에 맞춰 “회사소개형 프레임”으로 일부 섹션이 삭제된 상태로 자동 생성/조회 가능
